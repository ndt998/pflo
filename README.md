# NDT Portfolio — GitHub Pages

This folder is a fully static, bilingual portfolio ready for GitHub Pages.

## Publish

1. Create a public GitHub repository.
2. Upload everything inside this folder to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch **main**, folder **/(root)**.
5. Save and wait for the Pages deployment to finish.

All internal links are relative, so the site works both at `username.github.io` and at `username.github.io/repository-name/`.
